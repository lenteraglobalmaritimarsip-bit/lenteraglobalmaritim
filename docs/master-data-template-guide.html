Panduan Template Master Data

Fix Tariff dan Expenses Item - MaritimPort Admin

Dokumen ini menjelaskan fungsi setiap kolom, nilai yang diperbolehkan, contoh pengisian, dan alur upload template Excel ke Master Data.

1. Tujuan Template

Template Excel digunakan untuk memasukkan banyak data master sekaligus melalui menu Admin. Admin cukup mengisi satu baris untuk satu data, menyimpan file, lalu memilih tombol Upload Excel.

Catatan: Template dibuat langsung dari aplikasi dalam format .xlsx. Header kolom harus dipertahankan agar sistem dapat membacanya.

2. Template Fix Tariff

Fix Tariff berisi daftar tarif layanan berdasarkan pelabuhan. Data ini menjadi referensi harga ketika layanan dipakai pada proses quotation, PDA, atau perhitungan biaya.

Kolom Fix Tariff

KolomFungsiContoh / Aturan
portIdID unik pelabuhan dari Master Data Ports.Contoh: port-001. Boleh dikosongkan jika portName diisi dengan benar.
portNameNama pelabuhan untuk menghubungkan tarif dengan port.Contoh: Batu Ampar, Batam.
costCategoryKategori biaya layanan.PORT_EXPENSES, CLEARANCE, GENERAL_EXPENSES, CREW_EXPENSES, OWNER_MATTER, AGENCY_FEE.
tariffTypeJenis tarif yang digunakan.FIXED untuk tarif tetap, VARIABLE untuk tarif berubah, RANGE untuk tarif berdasarkan rentang.
serviceNameNama layanan atau item tarif.Contoh: Harbour Pilotage Service.
rateNilai tarif dasar.Contoh: 420. Isi angka tanpa simbol mata uang.
currencyMata uang tarif.Hanya USD atau IDR.
minChargeMinimum charge atau biaya minimum.Contoh: 500. Isi 0 jika tidak ada minimum.

Contoh Baris Fix Tariff

portId | portName | costCategory | tariffType | serviceName | rate | currency | minCharge port-001 | Batu Ampar, Batam | PORT_EXPENSES | VARIABLE | Harbour Pilotage Service | 0.038 | USD | 500
Perhatian: Kolom calculationBasis, serviceCode, dan description tidak ada di template karena tidak digunakan pada form tambah saat ini. Sistem otomatis memberi nilai default untuk field internal yang tidak ditampilkan.

3. Template Expenses Item

Expenses Item berisi daftar item biaya operasional. Data ini menjadi master referensi untuk biaya pembelian, biaya penjualan, quotation, dan actual cost.

Kolom Expenses Item

KolomFungsiContoh / Aturan
portIdID unik pelabuhan yang terkait dengan item biaya.Contoh: port-001.
portNameNama pelabuhan terkait.Contoh: Batu Ampar, Batam.
categoryKategori biaya item.PORT_EXPENSES, CLEARANCE, GENERAL_EXPENSES, CREW_EXPENSES, OWNER_MATTER, AGENCY_FEE.
calculationTypeMetode perhitungan item.FIXED, VARIABLE, QTY_RATE, PERCENTAGE, atau RANGE.
nameNama item biaya.Contoh: Tugboat Assistance.
unitSatuan penggunaan item.job, hour, day, qty, atau GRT.
defaultCurrencyMata uang default item.Hanya USD atau IDR.
rateRate atau standard cost item.Contoh: 420. Nilai ini mengisi standard cost buy dan sell.

Contoh Baris Expenses Item

portId | portName | category | calculationType | name | unit | defaultCurrency | rate port-001 | Batu Ampar, Batam | PORT_EXPENSES | QTY_RATE | Tugboat Assistance | job | USD | 420

4. Alur Upload

  1. Buka Admin lalu masuk ke Master Data Fix Tariff atau Expenses Item.
  2. Klik Download Template untuk membuat file Excel baru.
  3. Isi data mulai dari baris kedua. Jangan mengubah nama header.
  4. Simpan file dalam format Excel .xlsx.
  5. Klik Upload Excel dan pilih file tersebut.
  6. Sistem akan menampilkan jumlah data tersimpan, duplikat, dan baris tidak valid.

5. Aturan Validasi

  • serviceName wajib diisi untuk Fix Tariff.
  • name wajib diisi untuk Expenses Item.
  • currency atau defaultCurrency wajib berisi USD atau IDR.
  • Duplikat akan dilewati berdasarkan nama item, port, kategori, dan mata uang.
  • Nama kategori pada Excel menggunakan kode sistem, bukan label tampilan. Contoh: gunakan CLEARANCE, bukan teks CLEARANCE IN/OUT.
  • Angka tidak perlu diberi simbol mata uang atau pemisah ribuan.
